🔗 Dedicated Add / Edit Semantic Group Mapping Dialog #groupMappingModal

In SVG Animator Studio (:8088), clicking + Add Mapping or ✏️ Edit in the Group Inspector opens the dedicated 680px modal dialog with proactive compatibility filtering and Go-authoritative validation:
• Valid Example: cpu (number, 0..100) → Gauge Lite .value (number) + Text Box Lite .text (number → text conversion)
• Filtered / Rejected Example: Selecting color disables numeric value / period targets; setting opacity max > 1.0 or duplicate target bindings keeps Save Mapping disabled with field-specific feedback.
