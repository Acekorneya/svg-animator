# host-monitor-v1 — Portable SVG Widget Package

This directory contains a complete, portable, and ready-to-run SVG widget package exported from **SVG Animator Studio**.

## Quick Start

1. **Interactive Demo (No-Code):** Double-click `demo.html` in your browser. You can operate three independent live instances immediately with real-time controls.
2. **Standalone Asset:** `host-monitor-v1.svg` is the collision-free SVG file ready to embed in any web application.
3. **Properties Guide:** Read `host-monitor-v1-properties.md` for complete parameter specifications, object inventory, and integration code snippets.
